# Metadados das plataformas NANNAI

Consulte a documentação completa em [`docs/platforms/README.md`](../docs/platforms/README.md).

## Builds por target

- `web` — PWA + navegador (padrão)
- `capacitor` — Android e iOS
- `electron` — Windows desktop

A variável `VITE_BUILD_TARGET` controla `base` do Vite e inclusão do plugin PWA.
